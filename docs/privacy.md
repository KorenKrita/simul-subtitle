# 隐私说明

## 核心原则

- **音频绝不离机**：无论是手机还是电脑，语音识别都在本机离线完成，**任何情况下都不会上传或保存原始音频**。
- **使用记录默认关闭**：仅在「设置 → 使用记录」中手动开启后，才会在本机生成文字会话日志（不含音频、不含 API Key 与自定义请求头的值）；除非你主动导出或分享文件，日志永远留在本地。
- **字幕文本只存本机**：「设置 → 记录 → 保存字幕文本」默认关闭；打开后，每次会话把定稿的原文和译文存成一份纯文本，只有字幕里本来就显示的文字，没有声音、提示词或 Key；除非你主动分享，文件不会离开设备。已有的可以随时删除。
- **密钥系统级加密**：翻译服务（BYOK）的 API Key、自定义请求头的值以及 Jev Key 均使用各操作系统的硬件/账户级加密机制存储，不以明文落盘。

## 三端本地机制对比

| 维度 | Android | macOS | Windows |
|---|---|---|---|
| **音频采集方式** | `AudioPlaybackCapture`（内录其他 App 媒体/游戏声音，不用麦克风） | `sysaudio`（Core Audio Process Tap 捕获整机播放声音，不用麦克风） | `sysaudio.exe`（WASAPI Loopback 捕获默认播放设备声音，不用麦克风） |
| **配置与日志目录** | `Android/data/io.github.korenkrita.simulsub/files/` | `~/Library/Application Support/SimulSub/` | `%APPDATA%\SimulSub\` |
| **密钥加密存储** | **Android Keystore** 加密保存 | **macOS 登录钥匙串**（服务名 `SimulSub`，经 `security` 标准输入写入，不暴露于进程命令行参数） | **Windows DPAPI** 绑定当前 Windows 账户加密，存于 `keys.json`（其他账户或电脑无法解密） |
| **更新检查行为** | 读取公开版本清单，可在应用内下载并校验 APK 后拉起系统安装器 | 仅读取公开版本清单，发现新版时打开 GitHub 下载页 | 仅读取公开版本清单，发现新版时打开 GitHub 下载页 |
| **网络代理策略** | 跟随系统网络 / VPN | 跟随系统代理，代理不可达时回退直连 | 跟随系统代理，代理不可达时回退直连 |

## 会发送到网络的数据

语音识别模型随安装包内置，无需联网下载；仅以下三种场景会发起网络请求：

| 触发时机 | 接收方 | 发送内容 |
|---|---|---|
| **检查或下载更新**<br>（打开 App 时自动检查，可在「设置 → 关于」关闭；或手动点击检查） | `github.com`、`release-assets.githubusercontent.com`；直连失败时依次回退 `gh-proxy.com`、`gh.llkk.cc` | 仅发起普通的公开文件 GET 请求以获取版本清单 `update.json` 或安装包；**不附带**使用记录、音频、字幕文本、API Key 或设备唯一标识（服务端仅可见常规网络连接的 IP 等基础信息） |
| **实时翻译 / 测试连接 / 生成术语** | 你自己在设置中填写的 OpenAI 兼容服务地址 | 本地识别出的**纯文本**、场景说明与术语表、最近几句上文（如开启）、修正提示，以及你的 API Key 和高级设置中的 `User-Agent`、自定义请求头（首次使用某模型时还会发送一句固定的测试日语）。服务商如何处理这些文本由你所选服务商的隐私政策决定 |
| **开启 Jev 智能辅助**<br>（默认关闭） | 你选择的 Jev 服务渠道（OpenCode Zen / TypeSafe 官方 / OpenRouter） | 本地识别出的**原文文本**与**译文文本** |

> 关于自动检查更新：默认开启，仅在冷启动或从后台切回前台时检查一次（旋转屏幕、切换深浅色主题不会触发）；关闭后仅在手动点击「检查更新」时联网查询。

## 系统权限说明

### Android 权限列表

| 权限名称 | 实际用途 |
|---|---|
| **录音（`RECORD_AUDIO`）** | Android 系统规定内录其他 App 播放音频（`AudioPlaybackCapture`）必须申请此权限；**不读取麦克风** |
| **屏幕共享 / 投屏（`MediaProjection`）** | Android 内录其他 App 音频所必需的系统级授权弹窗；授权后仅采集手机内部播放的媒体与游戏音频 |
| **悬浮窗（`SYSTEM_ALERT_WINDOW`）** | 在其他应用上方绘制实时字幕悬浮窗 |
| **通知（可选）** | 显示前台服务运行状态与快捷「停止」按钮 |
| **网络（`INTERNET`）** | 请求翻译接口、Jev 辅助接口以及检查/下载版本更新 |
| **安装未知应用（`REQUEST_INSTALL_PACKAGES`，可选）** | 点击应用内「立即更新」后拉起系统安装界面；需你在系统设置中允许并亲自确认安装，绝不会静默安装 |

> **多应用同时发声提醒**：受操作系统音频内录接口机制决定，App 采集的是所有允许被内录的媒体、游戏或未分类声音（Android 的 `USAGE_MEDIA`、`USAGE_GAME`、`USAGE_UNKNOWN`，以及电脑端的系统混音输出），并未按单个进程隔离。若观看视频时后台有其他软件同时发声，其语音也可能被识别并发送给翻译接口；不想被识别的音源请在使用字幕期间暂停播放。

### 桌面端权限说明

- **macOS**：首次点击「开始字幕」时，系统会弹窗询问是否允许录制系统声音（可在「系统设置 → 隐私与安全性 → 屏幕与系统录音」中随时管理）。
- **Windows**：通过 WASAPI Loopback 读取默认播放设备输出，系统不弹出额外权限请求。
